## Honesty rule
No invented testimonials, client logos, case-study numbers, sales figures, rankings or "guaranteed" outcomes. Where evidence does not exist, the UI shows an honest empty state. Campaign reporting separates: work completed, activity delivered, observed results (with source + date range + methodology), and outcomes dependent on external platforms.
